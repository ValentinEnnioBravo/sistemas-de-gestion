# Glosario

← [[00 Índice]]

## Flujo de fondos

| Término | Significado |
|---|---|
| **FF / FC** | Flujo de fondos / flujo de caja |
| **Año 0** | Momento inicial: inversiones, WC inicial, préstamo, indemnizaciones del arranque |
| **IAI / EAI** | Ingresos / egresos **afectos** a impuestos (pasan por el estado de resultados) |
| **GND** | Gastos no desembolsables: depreciación, valor libro, quebranto trasladado |
| **Ajustes de GND** | Reversión de los GND (no son salida de caja) |
| **INAI / ENAI** | Ingresos / egresos **no afectos** (permutativos: inversión, préstamo, WC) |
| **UAI / EBIT** | Utilidad antes de impuestos |
| **UN** | Utilidad neta (después de IIGG) |
| **IIGG** | Impuesto a las ganancias |
| **Escudo fiscal** | Ahorro de impuesto por un gasto deducible (depreciación, intereses, pérdida) |
| **Quebranto** | Pérdida fiscal de la empresa → [[17 Quebranto impositivo]] |
| **Incremental** | Lo que aparece, desaparece o cambia por hacer el proyecto |
| **Costo hundido** | Ya gastado, no depende de la decisión → afuera |
| **Costo de oportunidad** | Lo que dejás de ganar por usar un recurso propio → EAI |
| **Devengado / percibido** | Corresponde a un período / efectivamente cobrado |
| **Horizonte** | Años que se evalúan (no necesariamente la vida útil) |
| **Flujo puro / del accionista** | Sin / con el préstamo → [[16 VAN puro vs VAN del accionista - apalancamiento]] |

## Ventas y costos

| Término | Significado |
|---|---|
| **Venta bruta** | P × Q vendida |
| **Venta neta** | Bruta − devoluciones − descuentos − IIBB |
| **Venta neta comercial** | Bruta − devoluciones − descuentos (sin restar IIBB) |
| **IIBB** | Ingresos brutos (impuesto provincial sobre la venta) |
| **Regalía (royalty)** | Pago por usar una marca o know-how → EAI |
| **Comisión** | % de la venta para vendedores → EAI (S&M), con CS salvo "no remunerativa" |
| **CMV** | Costo de la mercadería vendida (sobre lo vendido) |
| **CVu / CFu / CTu** | Costo variable / fijo / total unitario |
| **MOD** | Mano de obra directa |
| **CIF / gastos fabriles** | Costos indirectos de fabricación |
| **S&M / G&A** | Sales & marketing / generales y administrativos |
| **Markup** | % sobre el costo: P = C × (1 + mk) |
| **Margen** | % sobre el precio: P = C / (1 − m) |
| **Margen de contribución** | P − CVu |
| **Elasticidad precio** | ΔQ% / ΔP% (negativa en demanda normal) |
| **Desperdicio (scrap)** | Insumo perdido → comprar q / (1 − d) |
| **Obsolescencia** | Producto vencido o que no se vende → pérdida a costo |

## Inversiones

| Término | Significado |
|---|---|
| **Valor de origen (VO)** | Precio de compra del activo (sin IVA) |
| **Valor amortizable** | VO + transporte + instalación |
| **Depreciación / amortización** | Reparto lineal del valor amortizable en la vida útil (residual 0) |
| **Valor libro (VL)** | VO − depreciación acumulada |
| **Valor residual = rezago = reventa = salvamento** | Lo que te pagan al vender el activo |
| **Reinversión** | Compra de un activo durante el proyecto → [[11 Reinversión y desinversión]] |
| **Desinversión / desactivación** | Dar de baja (parte de) un activo; venta solo si te la dan |
| **CAPEX / OPEX** | Inversión de capital / gasto operativo |

## Capital de trabajo

| Término | Significado |
|---|---|
| **WC / CT** | Working capital = activo corriente − pasivo corriente |
| **Déficit acumulado máximo** | Método mensual para calcular el WC |
| **ΔWC** | Variación del WC (se invierte un año antes) |
| **Recupero** | Devolución del WC acumulado en el último año (INAI) |

## Financiación y evaluación

| Término | Significado |
|---|---|
| **TNA / TEA / TEM** | Tasa nominal anual / efectiva anual / efectiva mensual |
| **Francés / alemán / americano** | Cuota fija / amortización fija / capital al final |
| **Período de gracia** | Se difiere el capital (los intereses se pagan) |
| **Apalancamiento** | El préstamo sube el VAN del accionista |
| **WACC** | Costo promedio ponderado del capital |
| **Ke / Kd** | Costo del capital propio / de la deuda |
| **Xe / Xd** | Proporción de capital propio / de deuda |
| **CAPM** | Ke = Rf + β (Rm − Rf) [+ RP] |
| **Rf / Rm / RP** | Tasa libre de riesgo / rendimiento del mercado / riesgo país |
| **β (beta)** | Volatilidad de la acción respecto del mercado |
| **Prima de riesgo** | Rm − Rf |
| **ROE** | Utilidad neta / patrimonio neto (Ke si no cotiza) |
| **VAN / VNA** | Valor actual neto / función de Excel (sin el año 0) |
| **TIR** | Tasa que hace VAN = 0 |
| **Payback** | Año en que el flujo acumulado deja de ser negativo |
| **Equilibrio de largo plazo** | Valor que hace VAN = 0 |

## Laboral

| Término | Significado |
|---|---|
| **SAC / aguinaldo** | Sueldo anual complementario → 13 sueldos |
| **CS** | Cargas sociales (% sobre sueldos y comisiones remunerativas) |
| **En mano / de bolsillo** | Sueldo neto (⚠️ ver [[Dudas abiertas para consultar]]) |
| **Honorarios** | Pago a un monotributista o consultor (× 12) |
| **Haberes** | Sueldo de un empleado |
| **Indemnización** | Pago por despido (según enunciado) → EAI |
| **Ahorro de personal** | Sueldo que se deja de pagar → IAI |

## Jerga de la cátedra

| Término | Significado |
|---|---|
| **Bilardista** | Práctico, lo que se pide en el parcial |
| **Bielsista** | Más fino, lo de la vida real |
| **Formulador** | Quien escribió el enunciado (*"manda el formulador"*) |
| **Derivada quinta** | Un detalle demasiado fino para el parcial |
